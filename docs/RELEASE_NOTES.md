# Release Notes

## v0.4.6 (build 16) · October 25, 2026

- Added a Fingersonic family icon with blue drum-pad artwork and a video-play symbol, including standard macOS icon sizes.
- Made the container app visible in the Dock with its proper icon.
- Fixed Open Logic Pro: application discovery now supports Logic Pro and Logic Pro Creator Studio by bundle identifier and reports launch errors.
- Added an English installation and user guide covering the AUv3 container, unidentified-developer approval, MIDI mapping, recording, exporting, and media storage.
- Added an explicit arm64/x86_64 release build and packaging workflow, with separate AUv3, source, and complete ZIPs and SHA-256 checksums.
- Prepared all release documentation, verification notes, and filenames in English.
